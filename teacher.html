How the leaderboard works
  1. Students finish a round and send their name and score code through your Google Form.
  2. In the Google Form, open Responses, click the green Sheets icon, select all the rows, and copy them.
  3. Paste them in the box below. The page checks every code against the name it was typed with.
  4. Tick Count it for each name you approve. You can fix how a name will appear.
  5. Click Download leaderboard.js, then upload it to your GitHub repository (it replaces the old one). That is the only way names become public.

Automatic scores (set this up once)

With this on, a finished game sends the score to your Google Sheet by itself, and the leaderboard on the site reads the approved rows from the sheet. Nobody has to type or paste a code. You approve names by ticking a box in the sheet.
  1. Make the form. At forms.google.com, create a form with two short-answer questions: Name and Score code. In Settings, turn off “Collect email addresses”, “Limit to 1 response” and anything that makes students sign in.
  2. Make a pre-filled link. Click the three dots, then Get pre-filled link. Type the word NAME in the Name box and the word CODE in the Score code box, click Get link, and copy it. Paste it below.
  3. Open the sheet. In the form’s Responses tab, click the green Sheets icon. In the new sheet, type Approved in cell D1, select cells D2 to D1000, and choose Insert, then Tick box.
  4. Make the public tab. Click + at the bottom to add a second tab. In its cell A1 type Name, in B1 type Score code, and in A2 paste this (change the first tab’s name if it isn’t “Form Responses 1”):
    =FILTER('Form Responses 1'!B2:C, 'Form Responses 1'!D2:D=TRUE)
  5. Publish only that tab. Choose File, then Share, then Publish to web. Pick the second tab, set the format to Comma-separated values (.csv), click Publish, and copy the link. Paste it below.
Only rows you tick appear in that second tab, so only approved names are ever public.
Then upload settings.js to your GitHub repository, replacing the old one. Play one practice round on the site, tick it in the sheet, and watch it appear on the leaderboard.
